## 16. トラブルシューティング・よくある質問

**moum deck の曲が出ない / 「見つかりません」と出る**
moum deck を使っていない場合は、そのままで問題ありません。moum deck を使っている場合は、**設定 › moum deck** の **場所を指定…** で、`local_library.db` を選んでください。

**「使用中」と出る / 一覧が更新されない**
moum deck がデータベースを使っている最中は、一時的に読めないことがあります。前の一覧が表示されたままになり、しばらくすると自動で読み直されます。**今すぐ更新** でも読み直せます。

**M4A の曲が再生できない・取り込めない**
ffmpeg が必要です。設定 › ライブラリ › ffmpeg の **インストール…**（または再生できない曲のお知らせの **ffmpeg をインストール**）で入れてください。入れたあと、取り込みをやり直してください。

**CD の取り込みで、ALAC や AAC が選べない**
ffmpeg が必要です。上の項目のとおり、ffmpeg を入れてください。変換のウィンドウでも同じです。

**「CD ドライブが見つかりません。」と出る**
CD ドライブがつながっているか確かめて、ウィンドウの **更新** を押してください。CD の取り込みは Windows でだけ使えます。

**CD のジャケット（や、アルバム情報）が取得できない**
「ジャケット画像を取得できませんでした。」と出たときは、**再試行** を押してください。
インターネットにつながっているか、設定 › オンライン › 「ジャケットとタグをオンラインで検索」がオンか、確かめてください。
moum player は、通信のときに Windows の証明書の保存場所を使います。会社や学校のネットワークなどで、一部の PC で取得できなかった問題は、これで直ります。
それでも取得できないときは、時間をおいてからやり直すか、**画像を選択…** で手持ちの画像を使ってください。

**AccurateRip で「AccurateRip に登録がありません」と出る**
そのディスクの取り込み結果が、AccurateRip にまだ登録されていません。珍しいディスクや、新しく出たディスクでは起こります。取り込みの失敗ではありません。
取り込んだ音に問題がないかは、ここでは確かめられません。気になるときは、セキュアモードをオンにして、取り込み直してください。

**AccurateRip で「オフセット未設定」と出る**
ドライブの読み取りオフセットが決まっていません。「ドライブの読み取りオフセット（サンプル）」の欄に値を入れるか、**検出** を押してください（AccurateRip に登録のあるディスクが必要です）。
設定したあと、もう一度取り込むと、照合できます。

**AccurateRip で「一致しません」と出る**
ディスクの傷や汚れ、またはオフセットの違いが考えられます。ディスクを拭いて、セキュアモードで取り込み直してください。オフセットが正しいかも確かめてください。

**曲名がカタカナになっている（洋楽の日本盤）**
**設定 › オンライン › 洋楽のタイトルを原語で取り込む** をオンにしてください（初期設定でオンです）。CD を取り込むウィンドウの中にも、同じスイッチがあります。
この設定は、CD の取り込みと、アルバム情報の検索のときに使われます。すでに取り込んだ曲は、設定をオンにしてから、**アルバム情報をオンラインで調べる…**（§10-2）で調べ直してください。
曲名を置き換えるときは、曲名のチェックを入れてください。日本のアーティストの作品は、元の名前のままです。

**ストアの曲名が、ファイルの曲名と違う**
アルバム情報の検索では、ファイルにある曲名は、そのまま残ります。置き換えたいときだけ、曲名にチェックを入れてください（§10-2）。
CD の取り込みでは、ストア（iTunes や Deezer）で見つかったときは、ストアの表記を使います。気になるときは、一覧の曲名を取り込む前に直してください。
「曲名の取得元」で、MusicBrainz に切り替えることもできます（アルバム情報の検索のとき）。

**取り込んだ曲が moum deck に出ない**
- 設定 › moum deck › **取り込んだフォルダーを moum deck に追加** がオンか、確認してください。
- 「N個のフォルダーが追加待ちです」のような表示が出ているときは、**今すぐ再試行** を押してください。moum deck が起動中で、データベースが使えなかった可能性があります。
- 古い版の moum deck は、取り込み元の登録に対応していないことがあります。moum deck 側で、フォルダーを追加してください。

**ファイルのタグを書き換えたくない**
編集画面の「タグもファイルに書き込む」のチェックを外してください（設定 › タグ › 変更内容を音楽ファイルに書き込む も同じ設定です）。
すでに書き込んだ分は、**編集 › タグの書き込みを元に戻す…** で戻せます。

**タグを書き込んだのに、moum deck の表示が変わらない**
moum deck が、手が空いたときに読み直します。しばらく待つか、moum deck を起動し直してください。古い版の moum deck では、読み直しの依頼が残されません。

**変換した曲が、moum deck で古いファイルのままになっている**
moum deck を終了してから、**ファイル › ライブラリを書き出す…** の「この PC の moum deck」を実行してください（§7-3、§12-2）。

**ライブラリを書き出す › この PC の moum deck が実行できない**
moum deck を終了してから、もう一度実行してください。起動中は、何も書き込まれません。

**moum deck USB の書き出しで、曲が一部コピーされない**
書き出し後の結果に「N件のファイルをコピーできませんでした。ログを確認してください。」と出たら、ログを確認してください。元のファイルが見つからないときは、「N件のファイルが見つからないため、スキップします。」と出ます。

**購入元のアイコンに画像を選べない**
PNG・JPEG・SVG・ICO の画像だけが選べます。大きさは 2MB までです。名前を変えただけで、中身が画像でないファイルも選べません。

**起動が遅い**
ヘルプの **直近の起動タイミングをコピー** で、直近の起動時間をコピーできます。問題の連絡のときに、貼り付けて送ってください。
**起動ログのフォルダーを開く** で、記録ファイル（`startup_log.jsonl`）のフォルダーが開きます。
記録に入るのは、時間とバージョンの数字だけです。曲名やファイルの場所は入りません。直近 30回分が残ります。

**スプラッシュを出したくない**
設定 › 一般 › 起動画面を表示 をオフにしてください。

**画面が大きすぎる・小さすぎる**
Ctrl + / Ctrl − / Ctrl 0、または 設定 › 一般 › 表示サイズ で変えてください。

**「次はこちら」（キュー）が出ていない**
初めは閉じています。Ctrl Q、**表示 › キューを表示**、またはプレーヤーバーの **キュー** ボタンで開けます。ウィンドウが狭いときは、自動で隠れます。

**メディアキー（キーボードの再生・停止キー）**
対応していますが、実機での確認は十分ではありません。動かないときは、画面のボタンを使ってください。

**新しい版が出たか知りたい**
今のバージョンには、自動確認はありません。Releases のページで確認してください。
